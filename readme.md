Notatnik

Aplikacja do tworzenia notatek w C# i Avalonia. Notatki zapisują się do pliku notatki.md, najnowsza na górze. Program obsługuje polskie znaki i błędy zapisu.

Rundy

W folderze rundy/ znajdują się wyniki pięciu rund oraz powtórka rundy 3.

Powtórka rundy 3

Wynik różnił się od pierwszego: [wpisz różnice po porównaniu plików].

Różnice między rundami 1–4 mogły częściowo wynikać z losowości modelu, a nie tylko ze zmian w prośbie.

Obsługa błędów

Dodałem try/catch, aby aplikacja wyświetlała komunikat, gdy zapis się nie powiedzie.

Czas pracy: 2h.

Najtrudniejsze było: cale zadanie bylo trudne i agent nie robil tego o co go prosze.
